# makefun-two-days-excuses-01

One line, in the voice of an AI agent explaining a missed deadline — the gap between a machine's total confidence and its total failure, in 52 characters:

> I was 99.9% sure I'd hit the deadline. I rounded up.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (deterministic, Node standard library only, no network).
